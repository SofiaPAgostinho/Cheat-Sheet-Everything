# IntroPython

This folder contains introductory Python notebooks for learning programming basics, working with files, and creating plots. It includes practice exercises and a solutions notebook.

## Contents

- `S1_IntroPython.ipynb` — introduction to Python concepts and interfaces.
- `S1_PythonFilesandPlots_Cookbook.ipynb` — examples for handling files and visualizing data with Python.
- `S1_PythonFilesandPlots_Exercises.ipynb` — exercises on file handling and plotting.
- `S1_PythonFilesandPlots_Exercises_Solutions.ipynb` — solutions to the exercises.
- `resources/` — sample data and images used by the notebooks.
- `S1_IntroPython.zip` — zipped copy of the introductory notebook from previous versions.
