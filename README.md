## Subprojects

### [Bio_networks](./Bio_networks/)

An introduction to network biology, including a NetworkX notebook on disease modules and supporting graph theory and network biology course notes.

### [IntroPython](./IntroPython/)

Introductory Python notebooks covering core concepts, working with files, and creating plots. Includes exercises and their solutions.

### [Lab_3_Clustering](./Lab_3_Clustering/)

A lab notebook exploring clustering of RNA-seq data, with supporting data and visualization resources.

### [Pandas_cookbook](./Pandas_cookbook/)

Notebook-based examples and recipes for exploring and analyzing the Titanic dataset with pandas.
