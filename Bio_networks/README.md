# Bio Networks

This folder contains learning materials on network biology, graph theory, and the use of networks to study biological systems and disease.

## Contents

- `intro_network_biology_revised.md` — an introduction to network biology and graph theory, with topics including:
  - Building biological network models and choosing data resources.
  - Graph concepts, representations, distances, paths, and topology.
  - Node and network measures, centrality, connectivity, diffusion, and robustness.
  - Communities, biological modules, and methods for detecting them.
  - Network medicine, disease perturbations, and biological predictions.
- `TP1  Disease Modules with NetworkX.ipynb` — a practical notebook exploring disease modules in the human interactome. **Status: Work in progress.**
- `network-biology-assets/` — supporting network data and images.

## Graph theory introduction overview

The introduction document is organized into these main sections:

1. **Network Models to answer Biological Questions** — biological network types, data resources, static and dynamic models, and a reproducible construction workflow.
2. **Networks and Graph Theory** — graph basics, subgraphs, components, isomorphism, direction, and weights.
3. **Graph Representations and Edge Semantics** — adjacency and incidence matrices, edge lists, and neighbour lists.
4. **Network Characterisation: Distances and Paths** — paths and network-wide distance measures.
5. **Network Topology** — node and node-pair measures, centrality, connectivity, diffusion, structural organization, and robustness.
6. **Communities and Biological Modules** — dense subgraphs, modularity, community detection, and biological interpretation.
7. **From Network Biology to Network Medicine** — disease as a network perturbation, network-based predictions, and networks of networks.
